# Telegram OSINT Protection Bot

Полнофункциональный Telegram Mini App для защиты от OSINT-пробивов с backend на Python.

## 🚀 Возможности

### Frontend (React + TypeScript)
- 🎨 Премиальный космический дизайн с анимированной чёрной дырой
- 🛡️ Реальная система защиты с таймером
- 📊 Журнал угроз и системных событий
- 👑 Админ-панель для рассылок
- 📱 Полностью адаптивный интерфейс

### Backend (Python + aiohttp)
- 🤖 Telegram Bot с приветствием и inline-кнопками
- 💾 SQLite база данных для пользователей и логов
- 🔔 Реальные уведомления в ЛС при угрозах
- 📡 REST API для взаимодействия с Mini App
- 🛡️ Система мониторинга защиты

## 📋 Установка и запуск

### Backend
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python bot.py
```

### Frontend
```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## ⚙️ Настройка

1. **Замените URL backend'а** в `src/hooks/useTelegram.ts`:
   ```typescript
   const API_BASE_URL = 'https://your-backend-url.com/api';
   ```

2. **Установите webhook** для бота в `bot.py`:
   ```python
   webhook_url = "https://your-server.com/webhook"
   ```

3. **Настройте домен** для Mini App в Telegram BotFather

## 🔧 API Endpoints

- `POST /webhook` - Webhook для Telegram
- `POST /api/user` - Получение данных пользователя
- `POST /api/protection` - Включение/отключение защиты
- `POST /api/threat` - Добавление угрозы
- `POST /api/broadcast` - Админская рассылка
